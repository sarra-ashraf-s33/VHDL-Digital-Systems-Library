# 📑 VHDL Digital Systems Component Library

A structured VHDL collection covering foundational combinational and sequential digital logic components designed and tested using VHDL in VS Code.

## 📂 Repository Structure

### 🔀 Combinational Logic
- **Full Adder:** Arithmetic addition logic.
- **Encoder & Decoder:** Binary encoding and decoding logic.
- **Multiplexer (MUX) & Demultiplexer (DEMUX):** Signal routing modules.
- **Binary to BCD Converter:** Data format conversion.

### ⏱️ Sequential Logic
- **Flip-Flops & Latches:** Basic memory elements (SR, D, JK, T).
- **Registers:** Data storage and shifting registers.
- **Counters:** Synchronous/Asynchronous counter modules.

## 🛠️ Tools & Technologies
- **Language:** VHDL
- **Environment:** VS Code
- **Concepts:** RTL Design, Combinational Logic, Sequential Logic, Testbenches.
